### 문제 설명

<p>본 문제는 python 의 빠른 기초 학습을 위해 설계된 문제로서 python 코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
정수 2개(a, b)를 입력받아 합, 차, 곱, 몫, 나머지, 나눈 값을 자동으로 계산해보자.<br />
단, b는 0이 아니다.</p>

### 입력

<p>정수 2개가 공백을 두고 입력된다.<br />
&nbsp;</p>

### 출력

<p>첫 번째 줄에 합<br />
두 번째 줄에 차,<br />
세 번째 줄에 곱,<br />
네 번째 줄에 몫,<br />
다섯 번째 줄에 나머지,<br />
여섯 번째 줄에 나눈 값을 순서대로 출력한다.<br />
(실수, 소수점 이하 둘째 자리까지의 정확도로 출력)<br />
&nbsp;</p>

### 입력 예시

<pre>10 3</pre>

<pre>13
