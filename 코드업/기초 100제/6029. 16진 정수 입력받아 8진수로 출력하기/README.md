### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
16진수를 입력받아 8진수(octal)로 출력해보자. <br />
<br />
예시 <br />
a = input() <br />
n = int(a&#44; 16)&nbsp; &nbsp; &nbsp; #입력된 a를 16진수로 인식해 변수 n에 저장 <br />
print('%<span style="color:#E53333;">o</span>' % n)&nbsp; #n에 저장되어있는 값을 8진수(<span style="color:#E53333;">o</span>ctal) 형태 문자열로 출력 <br />
<br />
참고<br />
8진법은 한 자리에 8개(0 1 2 3 4 5 6 7)의 문자를 사용한다.<br />
8진수 10은 10진수의 8&#44; 11은 9&#44; 12는 10 ... 와 같다.<br />
<br />

### 입력

16진 정수 1개가 입력된다.<br />
<br />

### 출력

8진수 형태로 출력한다.<br />
<br />

### 입력 예시

<pre>f</pre>

### 출력 예시

<pre>17</pre>
