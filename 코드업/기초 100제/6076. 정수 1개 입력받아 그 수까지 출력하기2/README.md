### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
정수(0 ~ 100) 1개를 입력받아 0부터 그 수까지 순서대로 출력해보자. <br />
<br />
예시 <br />
n = int(input()) <br />
for i in range(n+1) : <br />
&nbsp; print(i) <br />
<br />
참고 <br />
range(n) 은 0&#44; 1&#44; 2&#44; ... &#44; n-2&#44; n-1 까지의 수열을 의미한다. <br />
예를 들어 range(3) 은 0&#44; 1&#44; 2 인 수열을 의미한다. <br />
<br />
for i in range(n) :&nbsp; &nbsp; #range(n)에 들어있는(in) 각각의 수에 대해서(for) 순서대로 i에 저장해 가면서... <br />
이때의 for는 각각의 값에 대하여... 라는 for each 의 의미를 가진다고 생각할 수 있다.<br />
<br />
range(끝)<br />
range(시작&#44; 끝)<br />
range(시작&#44; 끝&#44; 증감)<br />

	형태로 수열을 표현할 수 있다. 시작 수는 포함이고&#44; 끝 수는 포함되지 않는다. [시작&#44; 끝)
<br />

	증감할 수를 작성하지 않으면 +1이 된다.
<br />
<br />
반복 실행구조에 반복 횟수를 기록/저장하는 변수로 i를 자주 사용하는데&#44; <br />
i 는 반복자(iterator)를 나타내는 i라고 생각할 수 있다. i&#44; j&#44; k ... 알파벳 순으로 사용하기도 한다. <br />
<br />
