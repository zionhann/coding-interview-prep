### 문제 설명

<p>본 문제는 python 의 빠른 기초 학습을 위해 설계된 문제로서 python 코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
이번에는 큰따옴표(&quot;)(double quotation mark)가 포함된 출력문을 연습해보자.<br />
<br />
다음 문장을 출력하시오.<br />
<br />
&quot;Hello World&quot;<br />
(단, 큰따옴표도 함께 출력한다.)<br />
<br />
예시<br />
print(&#39; &quot; &#39;)<br />
<br />
참고<br />
python 언어에서 print( ) 로 출력할 문장을 표현할 때 큰 따옴표 기호(&quot;)로 묶어 표현한다.&nbsp;<br />
따라서, 큰따옴표 기호 그 자체를 출력하기 위해서는 다른 방법을 사용해야한다.<br />
python 언어에서 문장(문자열)을 표현하는 기호로 &quot;와 &#39;를 쌍으로 묶어 사용할 수 있다.<br />
따라서, 문장을 표현할 때 사용하는 큰따옴표(&quot;문장&quot;) 기호 대신 작은따옴표(&#39;문장&#39;)를 사용하면 큰따옴표를 출력할 수 있다.<br />
(물론, 큰따옴표를 출력하는 다른 방법도 있다.)&nbsp;<br />
<br />
