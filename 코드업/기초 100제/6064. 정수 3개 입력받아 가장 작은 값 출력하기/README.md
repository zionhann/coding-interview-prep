# [기초-3항연산] 정수 3개 입력받아 가장 작은 값 출력하기(설명)(py) - 6064

[문제 링크](https://codeup.kr/problem.php?id=6064)

### 성능 요약

시간 제한: 1 Sec, 메모리 제한: 128 MB

### 구분

코드업 > 기초 100제

### 문제 분류

기초-3항연산

### 채점결과

정확한 풀이

### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
입력된 세 정수 a&#44; b&#44; c 중 가장 작은 값을 출력하는 프로그램을 작성해보자. <br />
단&#44; 3항 연산을 사용한다. <br />
<br />
참고<br />
프로그래밍언어 소스코드 작성시 모든 요소들은<br />
"순서에 따라 한 단계씩 실행"<br />
"미리 정해진 순서에 따라 하나씩 연산 수행"<br />
"그 때까지 연산된 결과를 이용해 다시 순서에 따라 하나씩 연산"<br />
...<br />
등의 원리가 적용된다. <br />
<br />
따라서 3항 연산을 중첩해(괄호로 묶는 등..) 이용하면 여러 값들을 순서대로 비교해 가장 큰/작은 값을 계산할 수 있다.<br />
<br />
예를 들어 <br />
(a if a&gt;b else b) if ((a if a&gt;b else b)&gt;c) else c <br />
와 같은 계산식은 a&#44; b&#44; c 의 값 중 가장 큰 값으로 계산된다. <br />
<br />
잘 이해가 되지 않는다면 어떤 순서에 따라 계산될 지 생각해보고<br />
여러 가지 연산자가 동시에 사용된 식이 있을 때&#44; 어떤 우선순위에 따라 순서대로 계산이 되는지 찾아보도록 한다.<br />
“연산자 우선순위”를 검색하면 우선순위와 결합방향이 나온다.<br />
예를 들어 변수에 어떤 값을 대입하는 대입(assign) 연산자 = 의 우선순위는 가장 낮고&#44; 오른쪽에서 왼쪽의 결합방향을 가진다.<br />
<br />
** 3항 연산은 자주 사용되지는 않지만&#44; <br />
복잡한 계산식이나 조건 처리&#44; 비교 구조를 간단히 표현할 수 있게 해준다. <br />
<br />

### 입력

3개의 정수가 공백으로 구분되어 입력된다.<br />
-2147483648 ~ +2147483648 <br />
<br />

### 출력

가장 작은 값을 출력한다. <br />
<br />

### 입력 예시

<pre>3 -1 5</pre>

### 출력 예시

<pre>-1</pre>
