### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
3개의 정수(a&#44; b&#44; c)가 입력되었을 때&#44; 짝수만 출력해보자. <br />
<br />
예시 <br />
a&#44; b&#44; c = input().split() <br />
<br />
a = int(a) <br />
b = int(b) <br />
c = int(c) <br />
<br />
if a%2==0 :&nbsp; #논리적으로 한 단위로 처리해야하는 경우 콜론(:)을 찍고&#44; 들여쓰기로 작성 한다. <br />
&nbsp; print(a) <br />
<br />
if b%2==0 : <br />
&nbsp; print(b)&nbsp;<br />
<br />
if c%2==0 : <br />
&nbsp; print(c)&nbsp;<br />
<br />
참고&nbsp; <br />
if 조건식 : <br />
&nbsp; 실행1&nbsp; #조건식의 평가값이 True 인 경우 실행시킬 명령을 들여쓰기를 이용해 순서대로 작성한다. <br />
&nbsp; 실행2<br />
실행3&nbsp; #들여쓰기를 하지 않은 부분은 조건식에 상관이 없음&nbsp; <br />
<br />
<span>python</span> 에서는 논리적 실행단위인 코드블록(code block)을 표현하기 위해 들여쓰기를 사용한다. <br />
들여쓰기 방법은 탭(tab)&#44; 공백(space) 4개 등 여러 가지 방법을 사용할 수 있지만 <br />
한 소스코드 내에서 들여쓰기 길이와 방법은 똑같아야 한다. <br />
<br />
a%2==0 은 (a%2)가 먼저 계산된 후 그 결과를 정수 0과 비교한 결과값이다. <br />
a를 2로 나눈 나머지가 0&#44; 즉 짝수이면 True 가 되고&#44; 아니면 False 로 계산된다. <br />
따라서&#44; <br />
<span>if a%2==0 : #a가 짝수라면 ...&nbsp;</span> <br />
와 같은 의미가 된다. 짝수가 아니라면 들여쓰기로 작성된 부분들은 실행되지 않는다. <br />
<br />

### 입력

<br />

### 출력

짝수만 순서대로 줄을 바꿔 출력한다. <br />
