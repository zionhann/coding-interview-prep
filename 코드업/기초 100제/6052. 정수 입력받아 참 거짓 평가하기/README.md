### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
정수가 입력되었을 때&#44; True/False 로 평가해주는 프로그램을 작성해보자. <br />
<br />
예시 <br />
n = int(input()) <br />
print(bool(n)) <br />
<br />
참고 <br />
bool( ) 을 이용하면 입력된 식이나 값을 평가해 불 형의 값(True 또는 False)을 출력해준다.<br />
식이나 값을 계산해서 결과값이 만들어지는 것을 평가(evaluate)라고 한다.&nbsp;<br />
<br />
<span>python</span> 언어에서 정수값 0은 False(거짓)로 평가되고&#44; 그 외의 값들은 모두 True(참)로 평가된다. <br />
** 불&nbsp;대수(boolean algebra)는 수학자 불이 만들어낸 것으로 True(참)/False(거짓) 값만 가지는 논리값과 그 값들 사이의 연산을 다룬다. <br />

<br />

### 출력

입력된 값이 0이면 False&#44; 0이 아니면 True 를 출력한다. <br />
<br />

<pre>0</pre>

### 출력 예시
