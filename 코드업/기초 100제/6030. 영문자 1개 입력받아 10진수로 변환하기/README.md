### 문제 설명

<p>본 문제는 python 의 빠른 기초 학습을 위해 설계된 문제로서 python 코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
영문자 1개를 입력받아 10진수 유니코드(Unicode) 값으로 출력해보자.<br />
<br />
예시<br />
n = ord(input())<br />
print(n)<br />
<br />
참고<br />
n = ord(input())&nbsp; #입력받은 문자를 10진수 유니코드 값으로 변환한 후, n에 저장한다.<br />
<br />
ord( ) 는 어떤 문자의 순서 위치(ordinal&nbsp;position) 값을 의미한다.&nbsp;&nbsp;<br />
실제로 각각의 문자들에는 연속된 정수 값이 순서에 따라 부여 되어 있다. A:65, B:66, C:67 ....&nbsp;<br />
ord(c) : 문자 c 를 10진수로 변환한 값&nbsp;<br />
<br />
컴퓨터로 저장되고 처리되는 모든 데이터들은 2진수 형태로 정수화 되어야 하는데,<br />
컴퓨터에 문자를 저장하는 방법으로 아스키코드(ASCII Code)나 유니코드(Unicode)가 자주 사용된다.<br />
<br />
예를 들어, 영문 대문자 &#39;A&#39;는 10진수 값 65 로 표현하고,&nbsp;<br />
2진수(binary digit) 값 1000001 로 바꾸어 컴퓨터 내부에 저장한다.&nbsp;<br />
<br />
유니코드(unicode)는&nbsp;세계 여러 나라의 문자를 공통된 코드 값으로 저장할 때 사용하는 표준 코드이다.</p>

### 입력

<p>유니코드 영문자 1개가 입력된다.<br />
&nbsp;</p>

### 출력

<p>유니코드 값을 10진수로 출력한다.<br />
&nbsp;</p>

### 입력 예시

<pre>A</pre>

### 출력 예시

<pre>65</pre>
