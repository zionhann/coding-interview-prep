### 문제 설명

<p><span style="background-color:#ffffff">본 문제는 python 의 빠른 기초 학습을 위해 설계된 문제로서 python 코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------</span><br />
<span style="background-color:#ffffff">정수(integer)는</span><br />
<span style="background-color:#ffffff">양의 정수(1, 2, 3, 4, 5, ...), 음의 정수(-1, -2, -3, -4, -5, ...), 0 과 같이</span><br />
<span style="background-color:#ffffff">소숫점 아래에 수가 없는 수라고 할 수 있다.</span><br />
<br />
<span style="color:#333333">변수에 정수값을 저장한 후 정수로 변환하여&nbsp;출력해보자.</span><br />
<br />
<span style="color:#333333">예시</span><br />
n = input()<br />
n = int(n)<br />
print(n)<br />
<span style="color:#333333">와 같은 형태로 가능하다.</span><br />
<br />
<span style="background-color:#ffffff">참고</span><br />
<span style="color:#e53333">input</span>() 을 사용하면 키보드로 입력(<span style="color:#e53333">input</span>)한 값을 가져온다.</p>

<p>&nbsp;</p>

<p>변수 = input()<br />
를 실행시키면 키보드로 입력한 값을 왼쪽의 변수에 저장(할당, asign) 한다.<br />
<br />
변수는 어떤 값(정수, 실수, 문자, 문자열 등)을 저장할 수 있는 공간의 별명이라고 할 수 있다.<br />
변수는 일반적으로 알파벳(a~z, A~Z)이나 언더라인 &#39;_&#39;으로 시작하는 단어를 사용하고, 숫자(0~9)로 시작하는 단어는 사용할 수 없다.<br />
숫자로 시작하는 단어는 수로 인식하기 때문이다.<br />
(python의 경우 한글 변수도 사용할 수 있지만, 영문을 사용하는 것이 예상하지 못하는 오류를 방지할 수 있다.)<br />
<br />
&#39;=&#39; 연산자는 오른쪽의 계산 결과 값을 왼쪽의 변수에 저장하라는 의미의 대입연산자이다.<br />
왼쪽의 결과값과 오른쪽의 결과값이 같다는 의미의 수학식의 등호와는 의미가 다르다.&nbsp;<br />
&nbsp;</p>
