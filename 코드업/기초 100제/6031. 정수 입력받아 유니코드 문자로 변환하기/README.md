# [기초-값변환] 정수 입력받아 유니코드 문자로 변환하기(설명)(py) - 6031

[문제 링크](https://codeup.kr/problem.php?id=6031)

### 성능 요약

시간 제한: 1 Sec, 메모리 제한: 128 MB

### 구분

코드업 > 기초 100제

### 문제 분류

기초-값변환

### 채점결과

정확한 풀이

### 문제 설명

<p>본 문제는&nbsp;python&nbsp;의 빠른 기초 학습을 위해 설계된 문제로서&nbsp;python&nbsp;코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
10진 정수 1개를 입력받아<br />
유니코드 문자로 출력해보자.<br />
<br />
<br />
예시<br />
c = int(input())<br />
print(chr(c))&nbsp; #c에 저장되어 있는 정수 값을 유니코드 문자(chracter)로 바꿔 출력한다.&nbsp;<br />
<br />
<br />
참고<br />
입력은 기본적으로 모두 문자열로 입력되는 것이라고 할 수 있다.&nbsp;<br />
따라서, 입력 값이 문자/문자열/정수/실수인지에 따라서 먼저 정확하게 변환시킨 다음에 사용하거나 계산하는 것이 좋다.<br />
<br />
예를 들어 123 이 입력 되었다고 한다면, 이건 정수일까? 문자열일까?<br />
조금 생각해보면, 입력된 것만 보고는 그 값이 어떤 데이터인지 알 수 없다는 것을 쉽게 이해할 수 있다.<br />
따라서, 그 입력 값을 어떻게 해석하고 변환할 지에 대해서 명확하게 작성해 주어야 하는 것이다.&nbsp;<br />
<br />
chr( )는 정수값-&gt;문자, ord( )는 문자-&gt;정수값 형태로 바꿔주는 서로 반대 방향으로 바꾸어 주는 기능을 한다.<br />
&nbsp;</p>

### 입력

<p>10진 정수 1개(32 ~ 126 범위)가 입력된다.<br />
&nbsp;</p>

### 출력

<p>유니코드 문자로 출력한다.<br />
&nbsp;</p>

### 입력 예시

<pre>65</pre>

### 출력 예시

<pre>A</pre>
