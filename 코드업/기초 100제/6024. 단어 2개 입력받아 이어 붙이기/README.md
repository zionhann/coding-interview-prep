# [기초-입출력] 단어 2개 입력받아 이어 붙이기(설명)(py) - 6024

### 구분

코드업 > 기초 100제

### 문제 분류

기초-입출력

### 채점결과

정확한 풀이

### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
알파벳 문자와 숫자로 이루어진 단어 2개를 입력받아 <br />
순서대로 붙여 출력하는 프로그램을 작성해보자.<br />
<br />
예시<br />
w1&#44; w2 = input().split()<br />
s = w1 + w2<br />
print(s)<br />
<br />
참고<br />
단어는 문자(character)들로 만든다.<br />
문자들로 구성된 문장을 문자열(string)이라고 부른다.<br />
문자열에는 공백문자(' ')가 포함될 수 있는데&#44;&nbsp;<br />
문자 1개는 길이가 1인 문자열이라고 할 수 있고&#44; 공백문자(' ')가 없는 문자열은 단어(word)라고 할 수 있다.<br />
<br />
일반적인 문장들은 공백으로 구분된 단어들로 만들어지기 때문에&#44;<br />
공백문자로 구분된 문장에서 단어를 잘라내기 위해서는 공백문자(' ')를 기준으로 자르면 된다.<br />
키보드로 입력되는 것들은 기본적으로 문자열로 인식되고&#44; 문자열끼리 더하기(+)를 실행하면&#44;<br />
두 문자열을 합쳐 연결한(concatenate) 결과를 만들어 낸다.<br />
<br />

### 입력

알파벳과 숫자로 이루어진 2개의 단어가 공백으로 구분되어 입력된다. <br />
<br />

### 출력

입력된 2개의 단어를 순서대로 붙여 출력한다. <br />
<br />

### 입력 예시

<pre>hello world</pre>

### 출력 예시

<pre>helloworld</pre>
