### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
두 정수(a&#44; b)를 입력받아 <br />
a가 b보다 작으면 True 를&#44; a가 b보다 크거나 같으면 False 를 출력하는 프로그램을 작성해보자.<br />
<br />
예시<br />
print(123&lt;456)&nbsp; #비교 연산자 &lt; 의 계산 결과인 True(참)가 출력된다. <br />
(123&#44; 456 은 숫자로 작성된 단어이기 때문에 10진수로 인식된다.) <br />
<br />
참고<br />
어떤 값을 비교하기 위해 비교/관계(comparison/relational) 연산자(operator)를 사용할 수 있다.<br />
<br />
비교/관계연산자 &lt; (less than sign) 는<br />
왼쪽의 값이 오른쪽 값 보다 작은 경우 True(참)로 계산하고&#44;<br />
그 외의 경우에는 False(거짓)로 계산한다.<br />
<br />
비교/관계연산자도 일반적인 사칙연산자처럼 주어진 두 수를 이용해 계산을 수행하고&#44;<br />
그 결과를 True(참)&#44; 또는 False(거짓)로 계산해 주는 연산자이다.<br />
<br />
비교/관계연산자는 &lt;&#44; &gt;&#44; &lt;=&#44; &gt;=&#44; ==(같다)&#44; !=(다르다) 6개가 있다. <br />
<br />
True(참) 또는 False(거짓) 값으로만 표현하고 저장하는 값을 불(bool)/불리언(boolean) 값이라고 한다. <br />
정수&#44; 실수&#44; 문자&#44; 문자열과 마찬가지로 또 다른 형태의 데이터형(data type)이다.<br />

### 입력

두 정수(a&#44; b)가 공백을 두고 입력된다.<br />
-2147483648 &lt;= a&#44; b &lt;= +2147483647 <br />
<br />

### 출력

a가 b보다 작은 경우 True 를&#44; 그렇지 않은 경우 False 를 출력한다. <br />
<br />

### 입력 예시

<pre>1 9</pre>

### 출력 예시

<pre>True</pre>
