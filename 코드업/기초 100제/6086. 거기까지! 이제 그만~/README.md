### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
1&#44; 2&#44; 3 ... 을 순서대로 계속 더해 합을 만드는데&#44; <br />
그 합이 입력한 정수보다 작을 동안만 계속 더하는 프로그램을 작성해보자.<br />
<br />
즉&#44; 1부터 n까지 정수를 하나씩 더해 합을 만드는데&#44;<br />
어디까지 더해야 입력한 수보다 같거나 커지는지 알아보고자 하는 문제이다.<br />
<br />
하지만&#44; 이번에는 그 때 까지의 합을 출력해야 한다.<br />
<br />
예를 들어&#44; 57을 입력하면<br />
1+2+3+...+8+9+10=55에서 그 다음 수인 11을 더해 66이 될 때&#44;<br />
그 값 66이 출력되어야 한다.<br />
<br />
예시 <br />
... <br />
while True : <br />
&nbsp; s += c <br />
&nbsp; c += 1 <br />
&nbsp; if s&gt;=n : <br />
&nbsp; &nbsp; break <br />
<br />
print(s) <br />
<br />
참고<br />
조건문이나 반복문의 코드블록 안에서 break 가 실행되면&#44;<br />
반복실행을 중단(break)하고&#44; 가장 가까운 반복 블록의 밖으로 빠져나간다. <br />
<br />

### 입력

언제까지 합을 계산할 지&#44; 정수 1개를 입력받는다.<br />
단&#44; 입력되는 자연수는 100&#44;000&#44;000이하이다. <br />
<br />

### 출력

1&#44; 2&#44; 3&#44; 4&#44; 5 ... 순서대로 계속 더해가다가&#44; 그 합이 입력된 정수보다 커지거나 같아지는 경우&#44;<br />
그때까지의 합을 출력한다. <br />
<br />

### 입력 예시

<pre>57</pre>

### 출력 예시
