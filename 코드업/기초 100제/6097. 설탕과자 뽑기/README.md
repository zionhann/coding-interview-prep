### 입력

첫 줄에 격자판의 세로(h)&#44; 가로(w) 가 공백을 두고 입력되고&#44;<br />
두 번째 줄에 놓을 수 있는 막대의 개수(n)<br />
세 번째 줄부터 각 막대의 길이(l)&#44; 방향(d)&#44; 좌표(x&#44; y)가 입력된다.<br />
1 &lt;= w&#44; h &lt;= 100<br />
1 &lt;= n &lt;= 10<br />
d = 0 or 1<br />
1 &lt;= x &lt;= 100-h<br />
1 &lt;= y &lt;= 100-w <br />
<br />

### 출력

모든 막대를 놓은 격자판의 상태를 출력한다.<br />
막대에 의해 가려진 경우 1&#44; 아닌 경우 0으로 출력한다.<br />
단&#44; 각 숫자는 공백으로 구분하여 출력한다. <br />
<br />
