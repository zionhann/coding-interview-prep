### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
6자리의 연월일(YYMMDD)을 입력받아 나누어 출력해보자. <br />
<br />
참고 <br />
s = input() <br />
print(s[0:2]) <br />
<br />
를 실행하면 0번째 문자부터 1번째 문자까지 잘라 출력한다. <br />
s[<span style="color:#E53333;">a</span>:<span style="color:#E53333;">b</span>] 라고 하면&#44; s라는 단어에서 <span style="color:#E53333;">a번째 문자부터 b-1번째 문자까지</span> 잘라낸 부분을 의미한다. <br />
다른 자르기 방법도 있다.<br />
<br />

### 입력

6자리 숫자로 이루어진 연월일(YYMMDD)이 입력된다. <br />
<br />

### 출력

년도(YY) 월(MM) 일(DD)을 공백으로 구분해 한 줄로 출력한다. <br />
<br />

### 입력 예시

<pre>200304</pre>

### 출력 예시

<pre>20 03 04</pre>
