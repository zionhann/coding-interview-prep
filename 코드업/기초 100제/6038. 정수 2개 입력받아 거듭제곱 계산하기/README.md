### 문제 설명

<p>본 문제는 python 의 빠른 기초 학습을 위해 설계된 문제로서 python 코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
정수 2개(a, b)를 입력받아<br />
a를 b번 곱한 거듭제곱을 출력하는 프로그램을 작성해보자.<br />
<br />
예시<br />
...<br />
c = a**b<br />
print(c)<br />
<br />
참고<br />
python 언어에서는 거듭제곱을 계산하는 연산자(**)를 제공한다.<br />
일반적으로 수학 식에서 거듭제곱을 표현하는 사용하는 서컴플렉스/케릿 기호(^)는 프로그래밍언어에서 다른 의미로 쓰인다.<br />
&nbsp;</p>

### 입력

<p>2개의 정수(a, b)가 공백으로 구분되어 입력된다.<br />
&nbsp;</p>

### 출력

<p>a를 b번 거듭제곱한 값을 출력한다.<br />
&nbsp;</p>

### 입력 예시

<pre>2 10</pre>

### 출력 예시

<pre>1024</pre>
