### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
반복 횟수와 문장을 입력받아 여러 번 출력해보자. <br />
<br />
예시<br />
n = input()<br />
s = input()<br />
print(int(n)*s)<br />
<br />
참고<br />
문자열 * 정수 또는 정수 * 문자열은 그 문자열을 여러 번 반복한 문자열을 만들어 준다.<br />
<br />

### 입력

반복 횟수와 문장이 줄을 바꿔 입력된다. <br />
<br />

### 출력

입력된 횟수만큼 입력된 문장을 출력한다. <br />
<br />

### 입력 예시

<pre>3
I love CS</pre>

### 출력 예시

<pre>I love CSI love CSI love CS</pre>
