### 문제 설명

<p>본 문제는 python 의 빠른 기초 학습을 위해 설계된 문제로서 python 코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
정수 3개를 입력받아 합과 평균을 출력해보자.<br />
<br />
참고<br />
공백으로 구분된 한 줄로 값들을 입력받기 위해서는<br />
a, b, c = input().split()<br />
과 같은 방법이 가능하고,<br />
<br />
공백으로 구분해 두 값을 출력하기 위해서는<br />
print(d,&nbsp;e)<br />
와 같은 방법이 가능하다.<br />
<br />
잘라낸 값들은 그 값의 특성(정수, 실수, 문자, 문자열 ...)에 따라 명확하게 변환시킨 후 사용하는 것이 좋다.<br />
<br />
python 프로그래밍을 처음 배울 때 좋은 습관(단계)<br />
1. 입력된 문자열을 정확하게 잘라낸다.(공백, 줄바꿈, 구분문자 등에 따라 정확하게 잘라낸다.)<br />
2. 잘라낸 데이터들을 데이터형에 맞게 변환해 변수에 저장한다. (정수, 실수, 문자, 문자열 등에 따라 정확하게 변환한다.)<br />
3. 값을 저장했다가 다시 사용하기 위해, 변수를 이용해 값을 저장하고, 변수를 이용해 계산을 한다.<br />
4. 원하는 결과 값을 필요한 형태로 만들어 출력한다.(공백, 줄바꿈, 구분자, 등에 따라 원하는 형태로 만들어 출력한다.)<br />
&nbsp;</p>

### 입력

<p>정수 3개가 공백을 두고 입력된다.</p>

### 출력

<p>합과 평균을 공백을 두고 출력한다.<br />
평균은 소숫점 이하 셋째 자리에서 반올림하여 둘째 자리까지&nbsp;출력한다.</p>

### 입력 예시

<pre>1 2 3</pre>

### 출력 예시

<pre>6 2.00</pre>
