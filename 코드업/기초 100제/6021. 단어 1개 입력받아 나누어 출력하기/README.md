### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
알파벳과 숫자로 이루어진 단어 1개가 입력된다. <br />
입력받은 단어의 각 문자를 한 줄에 한 문자씩 분리해 출력한다. <br />
<br />
예시 <br />
s = input() <br />
print(s[0]) <br />
print(s[1]) <br />
... <br />
<br />
참고 <br />
s[0] 은 첫 번째 문자를 의미한다. <br />
<br />

### 입력

5개의 문자로 이루어진 단어 1개가 입력된다. <br />
<br />

### 출력

각 문자를 한 줄에 한 문자씩 줄을 바꿔 출력한다. <br />
<br />

### 입력 예시

<pre>Hello</pre>

### 출력 예시

<pre>H
e
l
l
o</pre>
