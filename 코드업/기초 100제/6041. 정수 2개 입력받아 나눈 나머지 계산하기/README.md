### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />

<br />
정수 2개(a&#44; b) 를 입력받아 a를 b로 나눈 나머지를 출력해보자. <br />
<br />
예시<br />
...<br />
print(a%b)<br />
<br />
참고<br />
<span>python</span> 언어에서는 나눈 나머지를 계산하는 연산자(%&#44; remainder)를 제공한다.<br />
a%b 와 같이 작성하면&#44; a를 b로 나눈 나머지(remainder)를 계산해준다. <br />
나머지 연산(modulus&#44; mod 연산)은 수학자 가우스가 생각해 낸 연산으로&#44;<br />
어떤 수를 다른 수로 나누고 난 후 남는 나머지를 계산하는 연산이다. <br />
<br />
실수로 나눈 나머지가 어떻게 계산될지도 생각해보자. <br />
