### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
어떤 규칙에 따라 수를 순서대로 나열한 것을 수열(sequences)이라고 한다. <br />
<br />
예를 들어<br />
1 4 7 10 13 16 19 22 25 ... 은<br />
1부터 시작해 이전에 만든 수에 3을 더해 다음 수를 만든 수열이다.<br />
이러한 것을 수학에서는 앞뒤 수들의 차이가 같다고 하여<br />
<br />
등차(차이가 같다의 한문 말) 수열이라고 한다. (등차수열 : arithmetic progression/sequence)<br />
수열을 알게 된 영일이는 갑자기 궁금해졌다.<br />
<br />
"그럼.... 123번째 나오는 수는 뭘까?"<br />
<br />
영일이는 프로그램을 만들어 더 큰 수도 자동으로 계산하고 싶어졌다.<br />
<br />
시작 값(a)&#44; 등차(d)&#44; 몇 번째인지를 나타내는 정수(n)가 입력될 때<br />
n번째 수를 출력하는 프로그램을 만들어보자.<br />

### 입력

시작 값(a)&#44; 등차의 값(d)&#44; 몇 번째 수 인지를 의미하는 정수(n)가<br />
공백을 두고 입력된다.(모두 0 ~ 100) <br />
<br />

### 출력

n번째 수를 출력한다. <br />
<br />

### 입력 예시

<pre>1 3 5</pre>

### 출력 예시

<pre>13</pre>
