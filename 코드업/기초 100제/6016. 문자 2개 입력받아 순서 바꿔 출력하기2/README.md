### 문제 설명

공백을 두고 문자(character) 2개를 입력받아 순서를 바꿔 출력해보자. <br />
<br />
참고<br />

	...
<br />

	print(c2&#44; c1)
<br />
와 같은 방법으로 출력하면&#44; c1과 c2에 저장된 값이 공백을 두고 순서가 바뀌어 한 줄로 출력된다.<br />
print( ) 안에서 쉼표(&#44;)를 찍어 순서대로 나열하면&#44; 그 순서대로 공백을 두고 출력된다.<br />
<div>
	<br />

### 입력

2개의 문자가 공백으로 구분되어 입력된다. <br />
<br />

### 출력

2개의 문자를 순서를 바꿔 한 줄로 출력한다. <br />
<br />

### 입력 예시

<pre>a b</pre>

### 출력 예시

<pre>b a</pre>
