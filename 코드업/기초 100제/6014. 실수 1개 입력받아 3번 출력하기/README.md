정확한 풀이

### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
실수(real number) 1개를 입력받아 줄을 바꿔 3번 출력해보자. <br />
<br />
예시<br />

	...
<br />

	print(f)&nbsp; #f에 저장되어있는 값을 출력하고 줄을 바꾼다.
<br />
print(f) <br />
print(f) <br />
와 같은 방법으로 3번 줄을 바꿔 출력할 수 있다. <br />
<br />
참고 <br />
<span>python</span> 코드 사이에 설명(주석)을 작성해 넣고 싶은 경우 샵('#') 기호를 사용하면 된다. <br />
#가 시작된 위치부터 그 줄을 마지막까지는 <span>python</span> 인터프리터에 의해서 실행되지 않는다. <br />
소스코드 부분 부분에 설명&#44; 내용&#44; 표시를 한 줄 설명으로 넣을 경우에 편리하게 사용할 수 있다. <br />
여러 줄로 설명을 넣는 방법도 있다. 스스로 찾아보자! <br />
<br />

### 입력

실수 1개가 입력된다. <br />
<br />

### 출력

입력받은 실수를 줄을 바꿔 3번 출력한다. <br />
<br />

### 입력 예시

<pre>0.1</pre>

### 출력 예시

<pre>0.1
0.1
0.1</pre>
