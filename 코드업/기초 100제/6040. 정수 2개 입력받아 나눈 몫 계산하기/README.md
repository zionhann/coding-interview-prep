### 문제 설명

본 문제는python의 빠른 기초 학습을 위해 설계된 문제로서python코드 제출을 기준으로 설명되어 있습니다.&nbsp;<br />
------<br />
<br />
정수 2개(a&#44; b) 를 입력받아 a를 b로 나눈 몫을 출력해보자. <br />
<br />
예시<br />
...<br />
print(a//b)<br />
<br />
참고<br />
python언어에서는 나눈 몫을 계산하는 연산자(//&#44; floor division)를 제공한다.<br />
a//b 와 같이 작성하면&#44; a를 b로 나눈 몫(quotient)을 계산해준다.<br />
프로그래밍언어에 따라 이렇게 몫을 계산해주는 연산자가 없는 경우도 있다. <br />
<br />
실수로 나눈 몫이 어떻게 계산될지도 생각해보자.<br />
<br />

### 입력

2개의 정수(a&#44; b)가 공백으로 구분되어 입력된다.<br />
<br />

### 출력

a를 b로 나눈 몫을 출력한다.<br />
<br />

### 입력 예시

<pre>10 3</pre>

### 출력 예시

<pre>3</pre>
