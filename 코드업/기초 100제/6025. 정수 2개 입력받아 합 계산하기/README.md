### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
정수 2개를 입력받아 <br />
합을 출력하는 프로그램을 작성해보자.<br />
<br />
예시<br />
a&#44; b = input().split()<br />
c = int(a) + int(b)<br />
print(c)<br />
<br />
참고<br />
입력되는 값은 기본적으로 문자열로 인식된다.<br />
<br />
문자열 + 문자열은 두 문자열을 합친 문자열을 만든다.<br />
숫자로 구성된 문자열이나 실수를 정수(<span style="color:#E53333;">int</span>eger) 값으로 바꾸기 위해서는 <span style="color:#E53333;">int</span>( ) 를 사용할 수 있다.<br />
수 + 수의 결과는 합(addition)이 계산된다.<br />
<br />

### 입력

2개의 정수가 공백으로 구분되어 입력된다. <br />
<br />

### 출력

두 정수의 합을 출력한다. <br />
<br />

### 입력 예시

<pre>123 -123</pre>

### 출력 예시

<pre>0</pre>
