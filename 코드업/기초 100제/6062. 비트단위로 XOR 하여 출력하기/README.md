### 문제 설명

<span>본 문제는 <span>python</span> 의 빠른 기초 학습을 위해 설계된 문제로서 <span>python</span> 코드 제출을 기준으로 설명되어 있습니다.&nbsp;</span><br />
<span>------</span><br />
<br />
입력된 정수 두 개를 비트단위로 xor 연산한 후 그 결과를 정수로 출력해보자. <br />
비트단위(bitwise) 연산자 ^(xor&#44; circumflex/caret&#44; 서컴플렉스/카릿)를 사용하면 된다.<br />
<br />
** 주의 ^은 수학식에서 거듭제곱(power)을 나타내는 기호와 모양은 같지만&#44;<br />
C언어에서는 전혀 다른 배타적 논리합(xor&#44; 서로 다를 때 1)의 의미를 가진다.<br />
<br />
** 비트단위(bitwise) 연산자는&#44;<br />
~(bitwise not)&#44; &amp;(bitwise and)&#44; |(bitwise or)&#44; ^(bitwise xor)&#44;<br />
&lt;&lt;(bitwise left shift)&#44; &gt;&gt;(bitwise right shift)<br />
가 있다.<br />
<br />
예를 들어 3과 5가 입력되었을 때를 살펴보면<br />
3&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;: 00000000 00000000 00000000 00000011<br />
5&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;: 00000000 00000000 00000000 00000101<br />
3 ^ 5 : 00000000 00000000 00000000 00000110<br />
이 된다.<br />
이러한 비트단위 연산은 빠른 계산이 필요한 그래픽처리에서도 효과적으로 사용된다.<br />
<br />
구체적으로 설명하자면&#44;<br />
두 장의 이미지가 겹쳐졌을 때 색이 서로 다른 부분만 처리할 수 있다.<br />
배경이 되는 그림과 배경 위에서 움직이는 그림이 있을 때&#44;<br />
두 그림에서 차이만 골라내 배경 위에서 움직이는 그림의 색으로 바꿔주면<br />
전체 그림을 구성하는 모든 점들의 색을 다시 계산해 입히지 않고<br />
보다 효과적으로 그림을 처리할 수 있게 되는 것이다.<br />
비행기 슈팅게임 등을 상상해보면 된다. <br />

### 입력

2개의 정수가 공백을 두고 입력된다.<br />
-2147483648 ~ +2147483647 <br />
<br />

### 출력

두 정수를 비트단위(bitwise)로 xor 계산을 수행한 결과를 10진수로 출력한다. <br />
<br />

### 입력 예시

<pre>3 5</pre>

<pre>6</pre>
